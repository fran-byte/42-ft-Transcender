# 📝 Evaluation Checklist — ft_transcendence Project

## 1. General Guidelines

- Git repository belongs to the evaluated team
- Only what is present in the repository is evaluated
- Careful review of each evaluation step
- Project must reach a **minimum of 14 module points**
- All team members must be present
- `git clone` performed in an empty folder
- No malicious aliases exist
- Review scripts used for testing/automation
- Evaluator has read all project materials
- Use flags for: empty repository, non-working program, Norm errors, cheating
- In case of cheating → final grade = **-42**
- In case of technical failure → final grade = **0**
